# P4：顺序状态融合与可观测性验证预注册

> 状态：已在代码实施前冻结。适用范围仅为 `synthetic_view_dependent` 虚拟立方体；不产生真实相机、真实机器人、CAD ADD/ADD-S 或算法优越性结论。

## 背景与问题

P3 的两轮数据未通过预期不确定性下降与下一步虚拟真值平移误差下降的一致性检验。当前实现还存在两个已知结构性缺口：每帧 bootstrap-ICP 协方差会覆盖上一帧协方差，且候选质量仅依赖静态投影面积。因此，P4 不沿用 P3 的收益声明，而检验一个新的、可导出的顺序诊断模型。

## 预先指定的模型

1. 状态以局部 6D 切空间表示。第 k 帧 ICP 输出测量 `(x_k, R_k)`；上一状态为 `(x_{k-1}, P_{k-1})`。
2. 在独立测量近似下使用信息形式融合：

   `P_k = (P_{k-1}^{-1} + R_k^{-1})^{-1}`

   `x_k = P_k (P_{k-1}^{-1} x_{k-1} + R_k^{-1} x_k^meas)`。

   所有协方差先对称化并施加最小特征值正则化；该近似仅用于虚拟诊断。
3. 候选可观测性由可见投影面积与视角新颖性相乘。新颖性为候选视线与已执行视线的最大余弦相似度的补量；首视点新颖性为 1。
4. 选择前记录由几何可观测性模型给出的预测后验；选择后记录 ICP 测量协方差融合得到的实际后验。模型输入不得使用下一步真值误差。

## 需要导出的逐视点字段

- `uncertainty_proxy_m`：选择前预测的平移标准差下降；
- `prior_covariance_translation_std_m`；
- `predicted_posterior_covariance_translation_std_m`；
- `covariance_translation_std_m`：融合后的实际后验；
- `visible_ratio`、`view_novelty`、`observability_score`；
- 下一步的虚拟真值平移误差（既有 `trans_error`）。

## 验证方案与通过门槛

- 场景：`none`、`light`、`heavy` 三个确定性遮挡级别；
- 策略：`uncertainty_only`、`path_cost_only`、`pose_gain`；
- 重复：每策略/场景至少 10 个匹配随机种子，最大 6 个视点；
- 主检验：所有有效多视点转移中，预测平移标准差下降与下一步虚拟真值平移误差下降的 Pearson 相关；
- 通过条件：`r >= 0.30`、bootstrap 95% 置信区间下界大于 0，且三个遮挡场景的相关方向均为非负；
- 未满足任一条件即报告负结果，不宣称 PoseGain 有效。策略性能比较是次要分析，不能替代主检验。

## 安全与可追溯性

仅允许无界面 Gazebo 与合成点云。配置快照必须保存随机种子、Git 提交、数据来源和 P4 模型名称。不得启动真实机械臂驱动、相机、夹爪 IO 或实体轨迹。
