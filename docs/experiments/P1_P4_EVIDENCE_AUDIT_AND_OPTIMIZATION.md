# P1--P4 证据审计与优化边界

> 日期：2026-07-29。本文不修改任何原始 CSV、不重定义既有门槛，也不把负结果改写为正结果。所有结论仅适用于纯虚拟、`synthetic_view_dependent` 立方体环境。

## 可保留的结论

| 阶段 | 当前证据支持 | 不能支持 |
| --- | --- | --- |
| P1 | 软件接口能在收到虚拟相机位姿后发布部分合成点云，且能记录遮挡/噪声配置。 | 该简化传感器等价于真实 RGB-D 的几何可见性，或任何真实相机精度结论。 |
| P2 | 在固定种子、候选集和最大视点数下，基线策略可重复运行并导出路径、时间、误差与可达率。 | 对真实场景、真实机器人或一般 NBV 的性能优越性结论；也不能把未做正式显著性检验的均值排序写成胜负结论。 |
| P3 | 主检验已经提供了反证：预测不确定性下降与下一步虚拟误差下降并不一致。 | `uncertainty_only` 或 `pose_gain` 有效/优越。 |
| P4 | 顺序融合、导出字段和预注册审计流程可运行，并明确暴露了校准失败。 | P4 协方差代理已校准，或 PoseGain 已通过虚拟验证。 |

## 现有定量证据

1. P2 的 90 个 episode（3 场景 × 3 基线 × 10 种子）是可重复的虚拟基线，但 `p2_baseline_summary.txt` 只报告描述统计；其观测模型是当时的简化合成模型。
2. P3 的 260 个多视点转移中，预测收益与下一步虚拟平移误差下降相关为 `r=-0.0325`；三个策略中的 `pose_gain` 为 `r=0.0338`。因此 P3 的策略比较只能作为探索性虚拟输出。
3. P4 的完整 90 个 episode 满足样本设计，但总体相关为 `r=0.0401`，95% bootstrap CI `[-0.0188, 0.1153]`，重遮挡为 `r=-0.0679`。
4. 对 P4 不可变 CSV 的附加诊断显示：81.6% 的转移融合后平移标准差低于 0.1 mm；重遮挡为 99.3%。P4 预测可见性与实际虚拟可见比例相关仅 `r=0.2012`；预测收益中位数约为零。

## 共因：观测与预测不匹配

P1--P4 的旧合成相机基于点法线与相机**位置**的正负关系筛选面，并进行与候选视角无关的随机删点；它没有使用候选相机姿态、成像平面或 z-buffer。P3/P4 却使用连续投影面积预测信息，因而预测器与实际生成的数据不共享同一观测机制。P4 还将共享同一云和模型的 ICP bootstrap 估计按独立测量累积，使协方差过度收缩。

## 优化方案（独立 P5，不回改 P1--P4）

1. **姿态感知虚拟相机**：将完整候选 `SE(3)` 位姿变换到相机坐标，投影到确定分辨率与视场的成像平面，并用 z-buffer 选择每像素最近的模型点。
2. **匹配的事前预测器**：候选评分在选择前调用同一离散模型；遮挡只作为已知场景条件的期望保留率，而不是读入下一帧或真值误差。
3. **保守不确定性融合**：以等权 covariance intersection 替代独立信息相加，避免对相关 ICP 估计双重计数。
4. **新的预注册与独立数据**：先检验预测可见性是否与实际可见比例一致、协方差是否仍塌缩；只有这两个校准门槛通过，才检验预测收益与误差改善，再讨论策略差异。

任何后续结果仍不能外推为真实相机、CAD ADD/ADD-S 或实体机械臂性能；回校后的硬件实验必须重新标定和单独预注册。
