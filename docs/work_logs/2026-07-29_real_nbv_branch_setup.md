# 工作日志：实测 NBV 分支建立

- 日期：2026-07-29
- 分支：`experiment/real-nbv`
- 基线：`main@d38bad0`（已验证的虚拟 NBV 实验管线与数据导出）

## 分支用途

该分支专用于后续实验室实际机械臂与真实传感器条件下的 NBV 测试开发。它与 `main` 的纯虚拟实验工作流隔离，避免硬件专用配置、现场标定结果或设备联调代码影响可复现的仿真基线。

## 当前状态

- 已继承合成点云、NBV 编排、实验导出和 MATLAB 分析所需的软件接口。
- 尚未加入真实机械臂控制命令、真实相机驱动配置、IP 地址、账号令牌或现场标定数值。
- 尚未执行任何硬件测试或发送任何运动指令。

## 后续接入顺序

1. 记录机械臂型号、控制器版本、相机型号和 ROS 2 驱动版本。
2. 在不使能运动的前提下验证机器人状态、点云话题、坐标系和时间戳。
3. 将手眼标定与工作空间/碰撞安全参数以可审计配置文件形式加入本分支。
4. 先完成低速、受监控的单次闭环测试，再运行批量 NBV 实验。
5. 每次实测均保存运行配置、随机种子、原始导出数据和异常记录。

## 安全边界

真实设备接入前必须由现场人员确认急停、速度限制、碰撞保护、工作空间和监控条件。本分支的建立本身不授权或触发任何实体设备动作。
